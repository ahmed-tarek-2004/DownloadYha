# Downloadyha

A simple YouTube downloader CLI built with Python and yt-dlp.

## Features

- Download YouTube videos
- Download audio as MP3
- Select video quality
- Select audio quality
- Choose download folder
- Uses Deno for JavaScript challenge solving
- Uses FFmpeg for media processing

## Requirements

- Python 3.10+
- FFmpeg
- Deno
